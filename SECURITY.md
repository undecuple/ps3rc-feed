# Security

## Reporting a problem

Do not report a security problem in a public issue.

- Use GitHub private vulnerability reporting on this repository: open the Security tab and choose "Report a
  vulnerability" (when that option is turned on).
- Or write to undecuple@proton.me.

Please include what you found, where, and how to see it. Do not include passwords, tokens or game files.

## What to expect

This is a small project run by one maintainer. A reply is not guaranteed on a fixed day. A real problem in the
collector, the workflows or the page will be fixed in the open once it is safe to describe.

## What is in scope

- The collector, the workflows and the site in this repository.
- A way for repository text on GitHub to run code or inject markup on the page, the Atom feed or a Discord message.
- A secret or token appearing in the repository, a workflow log or the published data.

Out of scope: a wrong game label or a listing you want removed. Use an issue on
[undecuple/me](https://github.com/undecuple/me/issues) or write to undecuple@proton.me for those.
